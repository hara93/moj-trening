# Third-party notices

## Tabler Icons

Some equipment icons in the exercise-library filter are taken from Tabler Icons
(https://tabler.io/icons), npm package `@tabler/icons` version 3.49.0, outline set
(`icons/outline/<name>.svg`). Changes: the 24×24 bounding-box helper path was removed
and `stroke-width` changed from 2 to 1.75; the drawing paths are unchanged.

| Tile | Tabler icon |
|---|---|
| Bez opreme | stretching-2 |
| Šipka | barbell |
| Girja | dumbbell |
| Pilates lopta | exercise-ball |
| Čunjevi | traffic-cone |
| Ostalo | dots |

The remaining equipment icons were drawn for this app in the same 24-px grid.
